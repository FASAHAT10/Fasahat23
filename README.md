# C Language Crash Course (Beginner to Advanced) 🚀

Assalam-o-Alaikum! Is repository mein hum C language ko bilkul shuru se (Basics) le kar Advanced level tak cover karein ge. Ye course Roman Urdu/Hindi mein hai taake aap ko samajhne mein aasani ho.

## Course Roadmap 🗺️

### 1. Basics (Shuruat) 🟢
- **Introduction to C:** C kya hai aur kyun zaroori hai?
- **Variables & Data Types:** Data ko store kaise karte hain?
- **Operators:** Calculations aur comparisons.
- **Control Flow:** If-else, switch case aur loops (for, while, do-while).

### 2. Intermediate (Darmayani Level) 🟡
- **Functions:** Code ko reuse kaise karein?
- **Arrays:** Multiple values aik hi variable mein.
- **Strings:** Text ke saath kaam karna.
- **Pointers:** Memory addresses ka khel.

### 3. Advanced (Maharat) 🔴
- **Structures & Unions:** Custom data types banana.
- **Dynamic Memory Allocation (DMA):** Runtime memory management.
- **Linked Lists & Stacks:** Bunyadi Data Structures.
- **Bitwise Operators:** Bits ke level par kaam.
- **Command Line Arguments:** Program ko bahar se input dena.
- **File Handling:** Files ko read/write karna.

### 4. Project Structure 🏗️
- **Multi-file Projects:** Code ko header aur source files mein bantna.

---

## Kaise Use Karein? 🛠️
1. Har folder mein aik `README.md` hogi jo us topic ko explain kare gi.
2. Saath mein `.c` files hongi jinhein aap compile kar ke chala sakte hain.
3. Compiling command: `gcc filename.c -o filename && ./filename`

Chalein, shuru karte hain!
