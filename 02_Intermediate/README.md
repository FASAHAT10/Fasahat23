# 02 Intermediate - Darmayani Level 🟡

Ab hum C language ki thori complex aur useful cheezein seekhein ge.

## 1. Functions
Functions code ka aik hissa hote hain jinhein hum bar bar bula (call) sakte hain. Is se code saaf rehta hai.
- `return_type`: Function kya wapis bheje ga (int, void, etc.)
- `parameters`: Function ko di jane wali maloomat.

## 2. Arrays
Agar humein aik hi kism ka bohat saara data store karna ho (jaise 10 bacho ke marks), to hum Arrays istemal karte hain.
- Index hamesha `0` se shuru hota hai.

## 3. Strings
C mein strings characters ka aik array hoti hain jinke aakhir mein null character `\0` hota hai.

## 4. Pointers
Pointers C language ka sab se zaroori topic hai. Pointer aik variable hota hai jo kisi doosre variable ka memory address store karta hai.
- `&` (Address of operator): Variable ka pata nikalne ke liye.
- `*` (Dereference operator): Pata par moojood value dekhne ke liye.

## Example Files:
- `functions.c`: Function banana aur istemal karna.
- `arrays.c`: Data ko list mein store karna.
- `strings.c`: Text ke saath kaam karna.
- `pointers.c`: Memory addresses ka istemal.
