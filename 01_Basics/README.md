# 01 Basics - Shuruat 🟢

Is section mein hum C language ki bunyadi cheezein seekhein ge.

## 1. Introduction to C
C aik powerful general-purpose programming language hai jo 1972 mein Dennis Ritchie ne banai thi.
- Ye "Case Sensitive" hai (Matlab `A` aur `a` alag hain).
- Har statement ke baad semi-colon `;` lagana zaroori hai.

## 2. Variables & Data Types
Variables memory mein aik container ki tarah hote hain jahan hum data store karte hain.

### Common Data Types:
- `int`: Pura number (e.g., 10, -5). Size: 4 bytes.
- `float`: Decimal wala number (e.g., 10.5). Size: 4 bytes.
- `char`: Aik single character (e.g., 'A'). Size: 1 byte.
- `double`: Bara decimal number. Size: 8 bytes.

### Variable Banane ka Tariqa:
```c
int age = 25;
float price = 99.99;
char grade = 'A';
```

## 3. Operators
C mein mukhtalif kism ke operators hote hain:
- **Arithmetic:** `+`, `-`, `*`, `/`, `%`
- **Relational:** `==`, `!=`, `>`, `<`, `>=`, `<=`
- **Logical:** `&&` (AND), `||` (OR), `!` (NOT)

## 4. Control Flow (Faisla Saazi)
- **If-Else:** Shart (condition) ke mutabiq code chalana.
- **Switch Case:** Aik variable ki mukhtalif values par kaam karna.
- **Loops:** Aik hi code ko bar bar chalana (`for`, `while`, `do-while`).

## Example Files:
- `hello_world.c`: Aap ka pehla C program.
- `variables.c`: Variables aur data types ka istemal.
- `operators.c`: Math aur comparisons.
- `control_flow.c`: If-else aur Loops ki misalein.
